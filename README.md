Manipulação de StringsExercícios focados no uso dos métodos nativos da classe String para tratamento e transformação de dados.MétodoDescrição🔍 ContainsVerifica se uma sequência de caracteres existe dentro de outra.✂️ TrimRemove espaços em branco antes e depois do texto.🎞️ SubstringExtrai partes específicas de um texto usando índices de início e fim.📍 Last Index OfEncontra a posição da última ocorrência de um caractere.🔄 ReplaceSubstitui trechos de texto ou caracteres por novos valores.🔠 Lower/UpperNormaliza textos para formatos totalmente minúsculos ou maiúsculos.2.
