Praticando Java: Strings e Regex ☕
Este repositório contém uma coleção de exercícios práticos desenvolvidos para consolidar o conhecimento em manipulação de textos e padrões de busca utilizando a linguagem Java.

📝 Conteúdo do Repositório
1. Manipulação de Strings
Exercícios focados no uso dos métodos nativos da classe String para tratamento de dados. As atividades cobrem:

Contains: Verificação de sequências de caracteres dentro de uma string.

Trim: Remoção de espaços em branco inúteis no início e no fim dos textos.

Substring: Extração de partes específicas de uma string através de índices.

Last Index Of: Localização da última ocorrência de um caractere ou subtitulo.

Replace: Substituição de caracteres ou trechos de texto por novos valores.

Lower & Upper Case: Conversão total de textos para letras minúsculas ou maiúsculas.

2. Expressões Regulares (Regex)
Implementação de padrões para validação e extração de informações complexas:

Validação de CPF: Padrão para identificar e validar o formato 000.000.000-00.

Segurança de Senhas: Criação de regras para senhas fortes (comprimento mínimo, caracteres especiais, números e letras).

Busca por Hashtags (#): Lógica para identificar e extrair palavras que começam com o símbolo #.
